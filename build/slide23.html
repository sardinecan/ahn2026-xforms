Les boutons -xf:trigger

Un xf:trigger est un bouton qui déclenche un évènement DOMActivate lorsque l’on clique dessus.


<xf:instance>
    <data xmlns="">
        <counter>0</counter>
    </data>
</xf:instance>
[…]
<xf:trigger>
    <xf:label>+ 1</xf:label>
    <xf:action ev:event="DOMActivate">
        <xf:setvalue ref="counter" value=". + 1"/>
    </xf:action>
</xf:trigger>
+ 1
Nombre de clics :

Mais on peut s’en servir pour plein d’autres de choses, par exemple, avec xf:load on peut mimer des liens hypertextes :


<xf:trigger>
    <xf:label>There is no dark side of the moon!</xf:label>
    <xf:action ev:event="DOMActivate">
        <xf:load resource="https://images.nasa.gov/details/art002e009287" show="new"/>
    </xf:action>
</xf:trigger>
There is no dark side of the moon!

Par défaut, la ressource est chargée dans la fenêtre courante, sauf si on utilise l’attribut @show="new".

L'attribut @appearance permet de changer la manière dont est représenté le bouton.


<xf:trigger appearance="minimal">
    <xf:label>There is no dark side of the moon!</xf:label>
    <xf:action ev:event="DOMActivate">
        <xf:load resource="https://images.nasa.gov/details/art002e009287" show="new"/>
    </xf:action>
</xf:trigger>
There is no dark side of the moon!

Si l’url doit être construite à partir des données du formulaire, l’attribut @source peut être remplacé par l’élément xf:resource :


<xf:instance id="urlParam">
    <data xmlns="">
        <q>art002e009287</q>
    </data>
</xf:instance>

<xf:load show="new">
    <xf:resource value="concat('https://images.nasa.gov/details/',instance('urlParam')/q)"/>
</xf:load>
There is still no dark side of the moon!
