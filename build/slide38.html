Attribute Value Templates (AVT)

Outre xf:output qui permet d’insérer du texte dans la page web, XForms permet aussi d’interagir avec les attributs HTML par l’intermédiaire de l’Attribute Value Templates :


<style type="text/css">
    .positif {color: green}
    .negatif {background-color: red; color: white}
</style>

L’AVT permet d’évaluer une expression à l’intérieur d’un attribut. Il s’agit d’une expression placée entre accolades { } à l'intérieur d'un attribut :


<span class="{if(age &lt; 0, 'negatif', 'positif')}">
    Âge au décès : <xf:output ref="age"/>
</span>
