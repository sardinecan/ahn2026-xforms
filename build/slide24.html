Module de soumission - xf:submission

Le module de soumission d’XForms est très complet et couvre un large éventail d’actions pour collecter, envoyer et stocker des données.

Il permet notamment de définir :

  • 1) ce qu’on souhaite envoyer
  • 2) où on souhaite l’envoyer
  • 3) ce qu'on veut faire du résultat

Tout ces paramètres sont définis avec l’élément xf:submission placé dans l'élément xf:model.

  • L’attribut @ref précise l’instance (ou le segment d’instance) qu'on souhaite envoyer (sans indication, il s’agit de l’instance par défaut) ; si on ne souhaite envoyer aucune donnée mais simplement en récupérer, on utilise l’attribut @serialization="none" ;
  • l’attribut @resource indique où envoyer et d’où recevoir les données ;
  • Enfin l’attribut @replace permet de spécifier ce qu'il faut faire des données reçues :
    • @replace="none" : ne rien faire
    • @replace="instance" : remplacer une instance. L’instance à remplacer est alors indiquée avec l’attribut @instance="idInstance"
    • @replace="all" : remplace toute la page

<xf:submission resource="https://juliettedrouet.univ-rouen.fr/lettres/jd.entry.3808/source"
    serialization="none" 
    method="get"
    replace="instance"
    instance="text-from-jd"/>
                        

<xf:submission
    resource="https://juliettedrouet.univ-rouen.fr/lettres/jd.entry.3808"
    serialization="none"
    method="get"
    replace="all"/>

Tout comme avec l’élément xf:load, si l’url à atteindre doit être construite, on peut remplacer l’attribut @resource par l’élément xf:resource.


<xf:submission
    serialization="none"
    method="get"
    replace="all">
    <xf:resource value="concat('https://juliettedrouet.univ-rouen.fr/lettres/', 'jd.entry.3808')"/>
</xf:submission>

On peut même avoir plusieurs processus de soumission au sein d’un même modèle. Il est alors nécessaire de leur attribuer un identifiant avec l’attribut @id :


<xf:submission id="gettext" ...

Pour déclencher une soumission, on a généralement recours à l’élément xf:submit :


<xf:submit>
    <xf:label>Récupérer le fichier TEI</xf:label>
</xf:submit>
<xf:submit submission="getview">
    <xf:label>Voir en ligne</xf:label>
</xf:submit>

Mais on peut aussi utiliser un xf:trigger :


<xf:trigger>
    <xf:label>Voir en ligne</xf:label>
    <xf:action ev:event="DOMActivate">
        <xf:send submission="getview"/>
    </xf:action>
</xf:trigger>
Récupérer le fichier TEI
Voir en ligne

En cas de soumissions multiple, il peut être préférable d’utiliser le mode de soumission synchrone (synchronous) (asynchronous par défaut) :


<xf:submission
    resource="https://juliettedrouet.univ-rouen.fr/lettres/jd.entry.3808"
    serialization="none"
    method="get"
    replace="all"
    mode="synchronous"/>

Ainsi, chaque soumission attendra que la précédente ait été finalisée avant de s’exécuter.
