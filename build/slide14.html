Typer les données - xf:bind

Au sein du xf:model, l’élément xf:bind est utilisé pour typer les données. Il est relié aux nœuds par l’intermédiaire de l’attribut @nodeset (groupe de nœuds) et le type est indiqué dans un attribut @type :


<xf:model>
    <xf:instance>
        <data xmlns="">
            <nom/>
            <dateNaissance/>
            <age/>
        </data>
    </xf:instance>
    <xf:bind nodeset="age" type="integer"/>
    <xf:bind nodeset="dateNaissance" type="date"/>
</xf:model>

Que remarque-t-on ?

Les champs s’adaptent aux types. Cependant, la valeur affichée peut ne pas correspondre à la façon dont elle est stockée (cf. date). Le non respect du type entraîne l’affichage d’une alerte.

On remarque également que l’utilisation de l’attribut @incremental="true" modifie l’évaluation du typage, qui se fait alors en temps réel.

Le type par défaut est string (chaîne de caractères), mais tous les types XML peuvent être appelés ; on peut même définir des types avec XML Schema :


<xs:schema targetNamespace="http://ahn2026/ns/1.0">
    <xs:simpleType name="phone">
        <xs:restriction base="xs:string">
            <xs:pattern value="^(\d{2}\s?){5}"/>
        </xs:restriction>
    </xs:simpleType>
    <xs:simpleType name="email">
        <xs:restriction base="xs:string">
            <xs:pattern value="^[^@]+@[^@]+"/>
        </xs:restriction>
    </xs:simpleType>
</xs:schema>

<xf:bind nodeset="//contact[@type='email']" type="ahn:email"/>
<xf:bind nodeset="//contact[@type='phone']" type="ahn:phone"/>
