Insertion - xf:insert

Jusqu'ici, nous avons vu comme modifier des valeurs, voyons maintenant comment modifier une instance plus en profondeur. Supposons que nous ayons une liste de personnes :


<xf:instance>
    <listPerson xmlns="">
        <person>
            <name>Victor Hugo</name>
            <birthDate>1802</birthDate>
            <deathDate>1885</deathDate>
            <age/>
        </person>
        <person>
            <name>Émile Zola</name>
            <birthDate>1840</birthDate>
            <deathDate>1902</deathDate>
            <age/>
        </person>
    </listPerson>
</xf:instance>
...
<xf:repeat nodeset="person">
    <xf:input ref="name"/>
    <xf:input ref="birthDate"/>
    <xf:input ref="deathDate"/>
    <xf:output ref="age"/>
</xf:repeat>

Il est possible d’ajouter une nouvelle personne à cette liste avec l’action xf:insert :


<xf:trigger>
    <xf:label>+</xf:label>
    <xf:hint>Ajouter une personne</xf:hint>
    <xf:action ev:event="DOMActivate">
        <xf:insert ref="person"/>
    </xf:action>
</xf:trigger>

Par défaut, le dernier élément est simplement dupliqué, avec les valeur qu’il contient.

Pour vider le contenu on peut procéder avec xf:setvalue à la suite de la copie :


<xf:trigger>
    <xf:label>+</xf:label>
    <xf:hint>Ajouter une personne</xf:hint>
    <xf:action ev:event="DOMActivate">
        <xf:insert ref="person"/>
        <xf:setvalue ref="person[last()]/name"/>
        <xf:setvalue ref="person[last()]/birthDate"/>
        <xf:setvalue ref="person[last()]/deathDate"/>
    </xf:action>
</xf:trigger>

Toutefois cette méthode ne fonctionne pas si la liste est vide. La solution est alors de faire appel à une seconde instance :


<xf:instance id="blank">
    <data xmlns="">
        <person>
            <name/>
            <birthDate/>
            <deathDate/>
            <age/>
        </person>
    </data>
</xf:instance>

Avec l’attribut @origin la procédure d’insertion se simplifie :


<xf:trigger>
    <xf:label>+</xf:label>
    <xf:hint>Ajouter une personne</xf:hint>
    <xf:action ev:event="DOMActivate">
        <xf:insert ref="person" origin="instance('blank')/person"/>
    </xf:action>
</xf:trigger>

Par défaut l’élément est ajouté à la fin de la liste, mais ce comportement peut être modifié :


<xf:trigger>
    <xf:label>+</xf:label>
    <xf:hint>Insérer une personne au début</xf:hint>
    <xf:action ev:event="DOMActivate">
        <xf:insert ref="person" at="1" position="before" origin="instance('blank')/person"/>
    </xf:action>
</xf:trigger>

Si on se trouve dans le contexte d’un élément xf:repeat, on peut même définir un index dynamique. Il est nécessaire d’attribuer un identifiant (@id) à l’élément xf:repeat. On peut alors utiliser la fonction index() pour déterminer une position :


<xf:repeat nodeset="person" id="indexPerson"/>

<xf:trigger>
    <xf:label>+</xf:label>
    <xf:hint>Insérer une personne au début</xf:hint>
    <xf:action ev:event="DOMActivate">
        <xf:insert ref="person" at="index('indexPerson')" position="before" origin="instance('blank')/person"/>
        <!-- <xf:insert ref="person[index('indexPerson')]" position="before" origin="instance('blank')/person"/> -->
    </xf:action>
</xf:trigger>
