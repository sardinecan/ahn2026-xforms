Miscelanea

XSLTForms implémente une série d’instruction et d’éléments qui ne font pas partie du standard XForms 1.1, mais qui peuvent être utiles.

xf:var

Les variables sont un ajout de XForms 2.0 :xf:var


<xf:var name="name" value="name"/>
<xf:output value="concat('Nom : ', $name)"/>

XForms Debugger

Accessible depuis la touche f1, on bénéficie, depuis le navigateur, d’une console XPath pour contrôler les instances de données. Il est aussi possible d’activer Fleur, un processeur XQuery en Javascript, mais ces fonctionnalités sont mal documentées.


<xf:var name="name" value="name"/>
<xf:output value="concat('Nom : ', $name)"/>

serialize()

Pour visualiser la sérialisation d’une donnée

transform()

transform() pour transformer une instance à l’aide d’un feuille XSLT


<xf:output value="transform(instance('text'),'../assets/xsl/tei2html.xsl', false)" mediatype="text/html"/>

is-valid()

La fonction is-valid() permet d’évaluer la validité d’un nœud. Un nœud est valide si les nœuds descendants sont valides également.


<div class="{ if(is-valid(.), 'valid', 'invalid') }">…</div>
