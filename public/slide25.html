Erreurs de soumission

Après une soumission, un événement est propagé à l'élément xf:submission :

  • xforms-submit-done en cas de succès
  • xforms-submit-error en cas d’échec

<xf:submission resource="maRessource" ...>
    <xf:action ev:event="xforms-submit-error">
        ...
    </xf:action>
</xf:submission>

Certains événements fournissent des informations supplémentaires accessibles via la fonction event(). C’est le cas avec xforms-submit-error qui dispose notamment de :

  • error-type : type d'erreur
  • error-message : détails supplémentaires
  • response-status-code : code HTTP du serveur (ex : 404)
  • response-reason-phrase : message du serveur (ex : "fichier introuvable")
  • resource-uri : URI utilisée pour la soumission

Ces informations peuvent être affichées dans une fenêtre modale à l’aide de l’élément xf:message :


<xf:submission resource="..." ...>
    <xf:action ev:event="xforms-submit-error">
        <xf:message>Erreur de soumission.
            type d'erreur : <xf:output value="event('error-type')"/>
            message : <xf:output value="event('error-message')"/>
            code de statut : <xf:output value="event('response-status-code')"/>
            raison : <xf:output value="event('response-reason-phrase')"/>
            URI : <xf:output value="event('resource-uri')"/>
        </xf:message>
    </xf:action>
</xf:submission>
