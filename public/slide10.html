Instances de données - xf:instance

L’élément xf:model peut contenir une ou plusieurs instances XML (xf:instance) :


<html>
    <head>
        <xf:model>
            <xf:instance>
                <data xmlns="">
                    <nom/>
                    <dateNaissance/>
                    <age/>
                </data>
            </xf:instance>
        </xf:model>
    </head>
    <body/>
<html>

Les instances peuvent être déclarées directement dans le modèle, comme nous venons de le voir, ou bien être issues de ressources externes (fichier local ou en ligne) à l'aide de l'attribut @src :


<xf:instance src="victorHugo.xml"/>
<xf:instance src="https://experts.huma-num.fr/xpr/biographies/xpr0027"/>

Il est impératif d’associer un espace de nom, même vide, aux instances sous peine de les voir interprétées comme des éléments XHTML.

Pour éviter les bugs avec Firefox (qui ne prend pas bien en charge les espaces de nom…), il convient de procéder avec *:bogus :


<html xmlns="http://www.w3.org/1999/xhtml"
    xmlns:ev="http://www.w3.org/2001/xml-events"
    xmlns:xf="http://www.w3.org/2002/xforms"
    xmlns:tei="http://www.tei-c.org/ns/1.0"
    xf:bogus="fix/Firefox/namespace/issue"
    xs:bogus="fix/Firefox/namespace/issue"
    tei:bogus="fix/Firefox/namespace/issue"/>
